# Hard Gel: Thin & Strong Nails

Next.js version of the Sams Nail Training landing page, ready for Vercel.

## Project structure

- `app/page.jsx` — page composition
- `components/` — one React component per website section
- `data/course.js` — benefits and course-module content
- `app/globals.css` — complete responsive styling
- `public/sam.jpg` — the supplied course photograph

## Deploy to Vercel

1. Extract this ZIP file.
2. Upload the folder to a GitHub repository, or import it with the Vercel CLI.
3. In Vercel, select **Add New → Project** and import the repository.
4. Keep the detected framework as **Next.js** and click **Deploy**.

No environment variables are required.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
